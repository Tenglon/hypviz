# hypviz

Interactive visualizations of hyperbolic machine learning — drag points on the
Poincaré disk and watch the Lorentz hyperboloid respond in real time.

Every scene compiles to a **self-contained HTML page** (offline-friendly, ~550 KB):
save it, email it, embed it in a course site. The same scene exports
**publication-grade vector SVG/PDF**, including configurations you arranged by
hand in the browser.

## Quickstart

```bash
pip install -e .
python examples/build_gallery.py    # -> examples/out/*.html, open in a browser
```

```python
from hypviz import DistanceLabel, Geodesic, Point, Scene

a = Point([0.45, 0.10], draggable=True, label="a", color="#2a78d6")
b = Point([-0.30, 0.45], draggable=True, label="b", color="#1baf7a")
scene = Scene([a, b, Geodesic(a, b), DistanceLabel(a, b)],
              views=("poincare", "lorentz"), curvature=-1.0, curvature_slider=True)

scene.to_html("geodesic.html")               # interactive page
scene.to_svg("figure1.svg", view="poincare") # paper figure
scene.to_svg("figure2.svg", state="scene-state.json")  # reproduce a browser arrangement
```

## Gallery (v1 scenes)

Prebuilt in `hypviz.scenes`; built into `docs/` by `tools/build_site.py` (GitHub Pages ready):

1. **Geodesic & distance** — the basic objects, live in two models
2. **Four models, one geometry** — the same triangle in Poincaré / Klein / half-plane / Lorentz
3. **exp & log maps** — the tangent-space arrow and the geodesic it unrolls into
4. **Möbius addition** — a⊕b ≠ b⊕a, with the gap measured live

Every page has a **curvature slider** (all views react: the bowl flattens as K → 0,
the unit-distance rings migrate outward) and a **download state** button for the
SVG round-trip.

## Architecture

- **Python numpy kernel** (`src/hypviz/kernel/`) — dimension-agnostic source of truth.
  Every operation is implemented once in Lorentz coordinates with curvature K < 0
  (the computational hub); Poincaré ball, Klein ball and half-plane are coordinate
  charts (`to_lorentz`/`from_lorentz`) on top. Optional torch/geoopt adapters at
  the boundary (`as_numpy`).
- **TypeScript mirror kernel** (`runtime/src/kernel/`) drives the real-time browser
  loop — single-stack three.js (orthographic 2D charts + perspective Lorentz view).
  Validated against **golden vectors** generated by the Python kernel across
  curvatures (`tools/gen_golden.py` → `runtime/golden/`).
- **Scene API** (`src/hypviz/scene.py`) — declarative primitives (`Point`,
  `Geodesic`, `LogVector`, `MobiusSum`, `TangentPlane`, `DistanceLabel`) whose
  references form the dependency graph the runtime re-evaluates on every drag.
- **Vector export** (`src/hypviz/export.py`) — a matplotlib backend that mirrors
  the runtime's drawing semantics.

## Development

```bash
pip install -e ".[dev]" && pytest             # kernel property tests (hypothesis)
cd runtime && npm install
npx vitest run                                # TS kernel vs golden vectors
npm run build                                 # bundle -> src/hypviz/_static/
node scripts/check_all.mjs                    # headless error check, all pages
node scripts/smoke.mjs                        # drag-interaction smoke test
python tools/gen_golden.py                    # regenerate golden vectors
python tools/build_site.py                    # rebuild docs/ gallery
```
