Density under different models & metrics — WordNet 'animal' (128-D)

The kernel density of the same embedded points. The four hyperbolic panels (Poincaré / Klein / half-plane / hyperboloid) render the identical intrinsic density — the models are isometric, so only the coordinate chart, hence the appearance, differs. Against them: the Euclidean kernel smears the density into a broad ring (it under-weights the exponential crowding near the boundary), and the cosine kernel collapses it to angular bands (it ignores radius entirely). Density concentrates at the boundary because that is where the deep, specific concepts live.
